# NotePaeds 9.3.1

Adds Tools → Blood investigation parser — FBC with reviewed preview and two-line output. Recognises HB/HGB/Haemoglobin, WBC, PLT/Platelets, PCV/HCT/Haematocrit, MCV and MCHC. Omits missing fields, RBC and MCH. Removes Markdown bold markers and redundant numerical trailing zeros; does not use reference ranges as results.

Selecting a medication in the existing search or ;; menu inserts immediately. Tab immediately after insertion or the small Edit medication button opens the tracked editor. Typing or moving the cursor ends that opportunity. Alt+Enter remains available later. Enter applies; Escape leaves the inserted text unchanged. Duration is editable alongside formulation, route, dose and frequency. IV fluids continue to open their structured calculation editor.

The medication library has not been replaced. The actual HTA November 2025 reference has not been supplied or found locally. That comparison and reviewed baseline/override update remain pending. No clinical dosing changes are asserted in this package.

Browser checks: 12 new workflow checks and all 53 existing ICD/library checks passed. Existing core source checks passed. Public release publication is separate.
